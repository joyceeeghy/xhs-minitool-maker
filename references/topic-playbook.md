# 话题构思 Playbook

## 小物件切入公式（已验证）

四步推导出一条能讲的线：

1. **选一个小物件**：身上佩戴/手边常用的小东西（腰带扣、玉佩、香囊、荷包、扳指……），越小越有「居然有这么多门道」的反差感。
2. **形态迁移线**：列出它在历代的形态（带钩 → 带銙 → 绔带 → 皮带扣），每代配一个代表实物。
3. **古今功能对照**：它的功能今天被什么继承了（蹀躞带七事 → 折刀/充电宝/打火机/卡包）。这一步是传播点——「古人的 XX 就是今天的 YY」。
4. **受众钩子**：用目标受众的行话重新叙述（对研发：剪裁=版型工程、纹样颜色=RBAC 权限系统、蹀躞带=EDC、楼层船=海上平台）。

## 内容结构模板（分享/长图文通用）

- 开场钩子：一个具体的历史故事（越戏剧性越好，如管仲射带钩改写历史）。
- 主线 ×3：每条线 = 1 张历代对比图 + 3-4 个节点 + 1 句金句。
- 番外同框：一个「穿越对比」彩蛋（楼船 vs 航母、被中香炉 vs 陀螺仪）。
- 收尾：一句贯穿性结论（如「两千年没变的问题：人身上最顺手的展位，一直是腰间和手腕」）。

## 已验证选题库（古风）

| 选题 | 主线 | 钩子 |
|---|---|---|
| 腰间两千年（已做） | 带钩→带銙→皮带扣 | 古人的 EDC |
| 鞋履（用户前作） | 舄→履→靴→球鞋 | 足下工程学 |
| 衣身演变 | 深衣→直裰→中山装→机能风 | 剪裁=版型工程 |
| 佩戴物 | 玉佩→怀表→腕表→智能手表 | 功能迁移：身份外显→能力延伸 |
| 水上平台（预告） | 楼船→宝船→航母 | 海上系统工程 |

## 拓展到外国文化（同一公式平移）

| 方向 | 小物件切入 | 形态迁移线 | 古今对照钩子 |
|---|---|---|---|
| 欧洲 | 束腰/紧身胸衣 | 克里诺林→巴斯尔→束腰→塑形衣 | 服饰即身体算法 |
| 欧洲 | 怀表链 | 日晷→怀表→腕表→智能表 | 时间的佩戴史 |
| 罗马 | 皮带（cingulum） | 罗马军带→中世纪骑士带→现代战术腰带 | 军人 EDC 两千年 |
| 日本 | 印笼/根付 | 印笼→烟草袋→腰包→机能挎包 | 没有口袋时代的挂载方案 |
| 中东/印度 | 头巾/披肩 | 身份织物→殖民地军服→秀场 | 织物的身份编码 |

要点：保持「小物件 + 迁移线 + 受众钩子」不变，只换文化语境；优先选与中国主题能对表的物件（便于做中外同框彩蛋）。

## 史料收集格式

每个物件记录：名称 / 年代 / 出土地或馆藏 / 形制一句话 / 冷知识或故事 / 参考图来源。事实须可追溯；拿不准的标注「说法存疑」（如中山装四袋=礼义廉耻的民间说法）。
