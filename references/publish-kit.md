# 小红书发布物料规范

## 四件套

| 物料 | 规格 | 说明 |
|---|---|---|
| 标题 | 有钩子、带主题词 | 例：「腰间两千年｜男人的腰带才是最早的 EDC」 |
| 描述 | **≤ 14 字** | 例：「一条腰带，串起两千年男装史」 |
| 封面图 | PNG，1024×1536（2:3，已验证可发布） | AI 生底图 + Pillow 排标题字；顶部留白防 UI 遮挡 |
| 工具图标 | PNG/JPG/JPEG，**≤5MB**，推荐 **1:1** | 例：青铜带钩图标；生成后检查大小，超标用 Pillow 压缩 |

## 发布文案结构（已验证）

1. 首行钩子（反差/悬念）；
2. 3-5 行内容亮点（每条一个 emoji 一个卖点：时间轴 / 对比墙 / 3D 试穿间）；
3. 玩法引导（扫码 → 拖到 3D 试穿间 → 点 AI 真人版）；
4. 话题标签（# 小红书小工具 # 国风 # 历史冷知识 等）。

**工具类变体**（万物计算器实证）：第 2 步改为分类清单式——按分类给 emoji 小标题 + 每类一行卖点；笔记第 2 页用「功能导览图」（真实首页全图截图 + 圆角卡片排版，1024×1536），比纯文字列表更直观。

## 命名与合规

- 工具名与封面标题一致，方便搜索（如「腰间两千年」）。
- 涉及真人姓名/公司的占位信息（如示例工牌）一律换成用户指定的中性文案。
- 图标/封面里 AI 生成的肖像避免拟真名人脸。
